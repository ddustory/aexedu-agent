# 🌏 다문화 학습 지원 에이전트

> 2026 Ax-Edu 해커톤 · ③ 포용·다문화 에이전트

이주배경 학생(베트남어·중국어·러시아어·몽골어를 쓰고, 한국어는 초급~중급)이 수업을 따라올 수 있도록
**교사를 돕는 AI 에이전트**입니다. 교사가 "이 학생을 위해 오늘 수업 자료를 만들어 줘" 같은 **목표**를 주면,
에이전트는 어떤 도구를 어떤 순서로 쓸지 **스스로 정해서** 여러 단계를 거쳐 일을 끝냅니다.

## 1. 이 에이전트가 하는 일

| 기능 | 교실에서 생기는 일 | 에이전트가 하는 일 |
|---|---|---|
| ① 쉬운 한국어 + 시각 자료 | 교과서 문장이 길고 한자어가 많아 이해하지 못함 | 학생 수준에 맞게 **쉬운 한국어**로 바꾸고, 핵심 낱말을 **어휘 카드**(쉬운 뜻 + 그림 아이콘 + 모국어)로 만듦 |
| ② 실시간 이중언어 지원 | 학생이 모국어로 질문함 / 교사 설명을 놓침 | 질문에 **쉬운 한국어 + 모국어**로 함께 답하고, 교사 설명을 **한국어/모국어 나란히** 보여줌 |
| ③ 맞춤형 비계(scaffolding) | 학생마다 필요한 도움의 양이 다름 | **진단 문제**로 시작 단계를 정하고, 수업 후 **확인 문제** 결과로 지원을 줄이거나(fading) 늘림 |
| ④ 학생 맞춤 낱말 | 같은 '쉬운 한국어'라도 학생마다 아는 낱말이 다름 | 학생별 **아는 낱말 기록**과 비교해, 같은 글을 **그 학생이 아는 말로** 바꿈. 학생이 **"좀 더 쉽게"**라고 하면 한 단계씩 더 쉽게 |
| ⑤ 지역 너머 또래 연결 (미리보기) | 지역아동센터는 그 지역 안에서만 모여, 수준 맞는 친구를 찾기 어려움 | **지역과 상관없이** 한국어 수준·학년이 비슷한 또래 4명 모둠을 제안 (같은 모국어 / 다른 모국어 중 교사가 선택) |

> **비계(scaffolding)**: 학생이 혼자 하기 어려운 과제를 할 수 있도록 임시로 주는 도움. 학생이 성장하면 점점 줄여 갑니다(fading).

### 지원 단계 (비계)

| 단계 | 이름 | 학생에게 주는 자료 |
|---|---|---|
| 1단계 | 모국어 중심 지원 | 쉬운 한국어 + **모국어 전체 번역** + 어휘 카드 8장 |
| 2단계 | 쉬운 한국어 중심 | 쉬운 한국어 + **핵심어만 모국어**(어휘 카드 5장) |
| 3단계 | 원문 + 필요할 때만 도움 | **원문 한국어** + 어려운 낱말 괄호 풀이 + 어휘 카드 3장 |

- **시작 단계(진단 문제 5개)**: 정답률 80% 이상 → 3단계 / 50% 이상 → 2단계 / 그 미만 → 1단계
- **수업 후(확인 문제 4개)**: 75% 이상 맞히면 지원 한 단계 줄이기 / 50% 미만이면 지원 한 단계 늘리기 / 그 사이는 유지

- **쉬운 한국어 기준**: 한 문장 평균 8어절 이하, 가장 긴 문장도 12어절 이하 (어절 = 띄어쓰기 단위). 넘으면 에이전트가 스스로 다시 고쳐 씁니다.
- **번역 검토**: 번역은 원어민 검토를 거치지 않은 **교사 확인용 보조 자료**로 표시하고, 사전에 없는 낱말의 어휘 카드에는 '교사 확인 필요' 표시를 붙입니다.

※ 위 기준은 현장 교사(도메인 담당)가 검토하고 확정한 값입니다. 다른 학교·학년에 맞출 때는 `agent/config.py` 의 숫자만 바꾸면 바로 반영됩니다.

## 2. 번역기(파파고)와 무엇이 다른가

> **파파고는 학생 대신 읽어 주고, 이 에이전트는 학생이 스스로 읽게 될 때까지 도와줍니다.**

번역기는 **1대1 입출력**입니다. 같은 문장을 넣으면 누구에게나 같은 결과 하나가 나오고, 그 결과에 학생이 모르는 낱말이 있어도 상관하지 않습니다.
이 에이전트는 **학생이 이미 아는 낱말 범위 안에서** 쉬운 말이나 비슷한 말로 바꿔 주어, 학생이 **자기가 쓸 수 있는 말로 표현하는 힘**을 기르게 합니다.

| | 번역기 (파파고 등) | 다문화 학습 지원 에이전트 |
|---|---|---|
| 결과 | 누구에게나 같은 결과 1개 | **학생마다 다른 결과** (아는 낱말 기록 기준) |
| 언어 | 다른 언어로 옮김 | **어려운 한국어 → 쉬운 한국어** (학생이 배워야 할 말은 한국어) |
| 시간이 지나면 | 계속 번역에 기댐 | 학생이 성장하면 **번역을 줄여 감(fading)** |
| "더 쉽게" | 다시 넣어도 같은 결과 | **"좀 더 쉽게"** 요청마다 한 단계씩 더 쉽게, 핵심 용어엔 풀이 |
| 수업 연결 | 없음 | 진단 → 단계 결정 → 교과 어휘 카드 → 확인 문제 → 다음 수업 계획 |
| 교사 | 학생마다 따로 번역 | 언어가 다른 학생 자료를 버튼 하나로, **판단 근거 기록** |
| 관계 | 혼자 씀 | **지역 너머 수준 비슷한 또래**와 연결 (본선 확장) |

**예: 같은 지문 첫 문장 "물은 지구 곳곳을 끊임없이 이동하며 모습을 바꾼다."**

| 학생 | 낱말 수준 | 에이전트 결과 |
|---|---|---|
| 린 (베트남어) | 1 | 물은 지구 **여러 곳을 계속 움직이며 모양을** 바꾼다. |
| 웨이 (중국어) | 2 | 물은 지구 곳곳을 **쉬지 않고** 이동하며 모습을 바꾼다. |
| 바트 (몽골어) | 2 (‘끊임없이’는 앎) | 물은 지구 곳곳을 끊임없이 이동하며 모습을 바꾼다. |
| 사샤 (러시아어) | 3 | (그대로) |

## 3. 왜 '에이전트'인가 (단순 챗봇과의 차이)

단순 챗봇은 "질문 한 번 → 답 한 번"입니다. 이 에이전트는 **목표를 받아 스스로 계획하고, 도구를 골라 쓰고,
결과를 확인한 뒤 다음 행동을 바꿉니다.**

```
교사의 목표: "린 학생을 위해 '물의 순환' 지문으로 수업 자료를 만들어 줘"
   │
   ▼
[에이전트 = Claude]  ── 다음에 무엇을 할지 스스로 결정 ──┐
   │                                                     │
   ├─ 👤 학생 정보 확인     → "아직 진단 전이네"          │
   ├─ 📝 한국어 수준 진단   → "정답률 40%"               │  도구 결과를 보고
   ├─ 🪜 비계 단계 결정     → "기준표에 따라 1단계"        │  다음 행동을 바꿈
   ├─ 🔍 원문 읽기 난이도 검사 → "문장이 너무 김(평균 11어절)" │
   ├─ ✏️ 쉬운 한국어로 바꾸기                              │
   ├─ 🔍 다시 검사(스스로 확인) → "통과(평균 5어절)"         │
   ├─ 🔎 어려운 낱말 찾기 → 🃏 어휘 카드 만들기              │
   ├─ 🌐 모국어 번역 (1단계라서)                            │
   └─ 📄 학습 자료 화면에 보여주기 ◀──────────────────────┘
```

- 학생이 **3단계**였다면 에이전트는 번역을 **하지 않고** 원문에 괄호 풀이만 넣습니다. 학생에 따라 **사용하는 도구와 순서가 달라집니다.**
- 쉬운 한국어로 바꾼 글이 기준을 못 넘으면 **스스로 다시 고쳐 씁니다.**
- 화면 왼쪽에 **어떤 도구를, 왜, 어떤 결과로** 썼는지 단계별로 모두 보입니다(실행 과정 트레이스).

### 에이전트가 쓰는 도구 (17개)

| 도구 | 하는 일 |
|---|---|
| 👤 학생 정보 확인 | 모국어, 한국 생활 기간, 교사 메모, 현재 지원 단계 |
| 📝 한국어 수준 진단 | 진단 문제 결과(정답률, 약한 영역) |
| 🪜 비계 단계 결정 | 기준표로 단계를 정하고 판단 근거를 기록 (진단/확인 문제 모두) |
| 🔍 읽기 쉬운지 검사 | 문장 길이(어절 수)와 어려운 낱말을 세어 통과/미달 판정 |
| ✏️ 쉬운 한국어로 바꾸기 | 단계별 규칙에 맞춰 다시 쓰기 |
| 🔎 어려운 낱말 찾기 | 교과 핵심 어휘 사전에서 찾기 |
| 🃏 어휘 카드 만들기 | 쉬운 뜻 + 아이콘 + 모국어 (사전에 없으면 AI가 만들고 '교사 확인 필요' 표시) |
| 🌐 모국어 번역 | 줄 단위로 맞춰 번역 (나란히 보기용) |
| ✅ 확인 문제 채점 | 수업 후 확인 문제 정답률 계산 |
| 🧩 학생이 아는 낱말인지 확인 | 학생별 낱말 수준 + 교사가 관찰한 '아는 낱말'과 비교해 바꿀 표현 찾기 |
| 🪄 학생이 아는 말로 바꾸기 | 핵심 용어는 그대로 두고, 나머지 어려운 표현만 학생이 아는 말로 |
| 🤝 지역 너머 또래 찾기 | 한국어 단계·학년이 비슷한 또래를 지역과 상관없이 찾아 모둠 구성 |
| 📄 / ↔️ / 📋 화면에 보여주기 | 학습 자료 / 이중언어 나란히 / 지원 계획 / 학생 맞춤 글 / 또래 모둠 |

## 4. 시연 화면 사용법

처음 실행하면 **예시 지문(「물의 순환」, 새로 작성)** 과 **가상 학생 4명**이 이미 들어 있습니다.

1. 왼쪽에서 학생을 고릅니다. (린-베트남어 / 웨이-중국어 / 사샤-러시아어 / 바트-몽골어)
2. **① 수업 자료 만들기** 탭에서 빨간 버튼을 누르면, 왼쪽에 에이전트가 일하는 과정이, 오른쪽에 완성된 자료가 나옵니다.
   - 학생마다 진단 결과가 달라서 **1·2·3단계 자료가 각각 다르게** 만들어지는 것을 비교해 보세요.
3. **② 실시간 이중언어 도우미** 탭: 학생의 모국어 질문에 답하기 / 교사 설명 나란히 보기
4. **③ 확인 문제 → 지원 단계 조정** 탭: 맞음/틀림을 바꿔 가며 눌러 보면, 지원이 줄거나 늘어나고 그 **이유**가 기록됩니다.
5. **④ 학생 맞춤 낱말** 탭: **맞추기**를 누른 뒤 **🔁 좀 더 쉽게**를 눌러 보세요. 아래에는 같은 글이 네 학생에게 각각 어떻게 바뀌는지 나란히 보입니다.
6. **⑤ 지역 너머 또래 연결** 탭: '같은 모국어 / 다른 모국어'를 골라 모둠을 만들어 보세요. 같은 지역 안 후보 수와 지역을 넘은 후보 수가 비교됩니다.
7. 왼쪽 아래 **처음부터 다시** 버튼으로 초기화할 수 있습니다.

### 두 가지 실행 모드

| 모드 | 언제 | 무엇이 다른가 |
|---|---|---|
| 🎬 오프라인 시연 모드 | API 키가 **없을 때** (기본) | 도구(진단, 단계 결정, 가독성 검사, 어휘 사전, 채점)는 **실제로 실행**됩니다. AI가 글을 쓰고 도구를 고르는 부분만 **미리 준비된 시나리오**로 재생합니다. 예시 지문·예시 질문만 쓸 수 있습니다. (④ 학생 맞춤 낱말 바꾸기와 ⑤ 또래 연결은 어떤 글·학생으로도 실제로 동작합니다.) |
| 🟢 실시간 AI 모드 | API 키를 **넣었을 때** | Claude 가 직접 도구를 고르고 글을 씁니다. **새 지문, 새 질문**도 쓸 수 있습니다. |
| 💻 로컬 AI 모드 | 내 컴퓨터에 **Ollama**가 있을 때 (API 키 없음) | 노트북 안에서 도는 오픈 AI 모델(기본 `qwen3:8b`)이 도구를 고르고 글을 씁니다. **인터넷·사용료 없이**, 학생 정보가 **컴퓨터 밖으로 나가지 않습니다.** 작은 모델이라 Claude보다 느리고 번역이 서툴 수 있습니다. 공유 링크(Streamlit)에서는 쓸 수 없고 내 컴퓨터에서 실행할 때만 됩니다. |

## 5. 실행 방법

### 가장 쉬운 방법 (내 컴퓨터)

1. (Python을 따로 설치하지 않아도 됩니다. 실행 파일이 시연에 맞는 Python 3.12를 자동으로 준비합니다.)
2. 이 저장소를 내려받습니다. (GitHub 화면의 초록색 **Code → Download ZIP** → 압축 풀기)
3. 폴더 안의 파일을 **더블클릭**합니다.
   - 윈도우: `run_windows.bat`
   - 맥: `run_mac.command` (처음에 "열지 않음" 경고가 뜨면 **시스템 설정 → 개인정보 보호 및 보안** 맨 아래의 **그래도 열기**)
4. 잠시 후 브라우저에 시연 화면이 열립니다. (처음 한 번은 설치 때문에 2~3분 걸립니다)

### 로컬 AI 모드 쓰기 (무료 · 내 노트북 안에서)

1. [ollama.com](https://ollama.com/download) 에서 Ollama를 내려받아 설치하고, 한 번 실행합니다.
2. `run_mac.command`(윈도우는 `run_windows.bat`)를 더블클릭합니다. 처음 한 번은 AI 모델(약 5GB)을 자동으로 내려받습니다.
3. 화면 위에 **💻 로컬 AI 모드**가 표시되면 성공입니다. (메모리 16GB 이상 노트북 권장)

### API 키 넣기 (실시간 AI 모드를 쓰고 싶을 때)

1. [Claude 콘솔](https://console.anthropic.com/) 에서 API 키를 만듭니다.
2. 폴더 안의 `.env.example` 파일을 복사해서 이름을 `.env` 로 바꿉니다.
3. `.env` 파일을 메모장으로 열어 `ANTHROPIC_API_KEY=` 뒤에 키를 붙여 넣고 저장합니다.
4. 실행 파일을 다시 더블클릭하면 화면 위에 **🟢 실시간 AI 모드** 가 표시됩니다.

> `.env` 파일은 GitHub에 올라가지 않도록 설정되어 있습니다. 키를 다른 사람과 공유하지 마세요.

## 6. 안전·윤리

- **가상 학생만 사용**: 이름, 연락처 등 실제 학생 개인정보는 코드와 데이터 어디에도 없습니다.
- **교사 확인용 보조 자료**: 번역과 쉬운 한국어 변환은 완벽하지 않을 수 있어, 화면에 항상 안내 문구를 표시합니다.
  사전에 없는 낱말로 AI가 만든 어휘 카드에는 '교사 확인 필요' 표시가 붙습니다.
- **교육적 판단은 교사 기준대로**: 단계 결정은 AI 마음대로가 아니라 교사가 정한 기준표(`agent/config.py`)로만 이루어지고, 판단 근거가 기록됩니다.
- **저작권**: 예시 지문과 문제는 교과서를 베끼지 않고 새로 작성했습니다.
- **API 키 보호**: 키는 `.env` 파일로만 관리하고 저장소에 올리지 않습니다.
